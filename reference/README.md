## ECC (`reference/ECC`) — сабмодуль, запинен на коммит `40927950`

[`affaan-m/ECC`](https://github.com/affaan-m/ECC) («Everything Claude Code», MIT). Добавлен как **git-сабмодуль** (ссылка на upstream, а не копия файлов в наше дерево) на случай «вдруг пригодится». Полный разбор — почему не вендрили в `.claude/skills/` — в [../README.md](../README.md) (раздел «ECC») и [../SKILLS-RESEARCH-2026-07-11.md](../SKILLS-RESEARCH-2026-07-11.md) (раунд 4).

**Статус: карантин.** Это не проверенный набор:

- ❌ **Не активен.** 278 скиллов / 67 агентов / хуки ECC не загружаются этим репозиторием и не участвуют в наших сессиях. Так и задумано — иначе описания перебьют наши курируемые скиллы (тот самый «вред двойного срабатывания»).
- ❌ **Не запускать инсталлеры/скрипты.** `install.sh`, `install.ps1`, Node-скрипты, `ecc_dashboard.py`, авто-хуки, self-learning (`evaluate-session.js`, пишет в `~/.claude` и `~/.local/share/ecc-homunculus`), `auto-update.js` (делает `git pull` и пробрасывает весь `process.env`) — **не прогонялись через наш пофайловый веттинг**. Не выполнять.
- ✅ **Можно читать и брать по кусочку.** Если позже понадобится конкретный markdown-скилл — скопировать **один файл** в `.claude/skills/<name>/`, прогнать по чеклисту из `SKILLS-RESEARCH` (prompt-injection в прозе, скрытые символы, внешние эндпоинты, коллизия описаний) и только потом коммитить.

### Как это использовать

```bash
# подтянуть содержимое сабмодуля (по умолчанию клон — только указатель):
git submodule update --init reference/ECC

# посмотреть, что есть:
ls reference/ECC/skills reference/ECC/agents

# ОДИН полезный отделяемый инструмент — сканер безопасности, без принятия системы:
npx ecc-agentshield scan            # аудит permission/hook/MCP + секрет-детект
npx ecc-agentshield scan --opus     # состязательная кросс-проверка тремя агентами
```

### Обновить пин

```bash
git -C reference/ECC fetch origin && git -C reference/ECC checkout <new-sha>
git add reference/ECC && git commit -m "Bump ECC reference to <new-sha>"
```

Перед тем как что-либо отсюда активировать — перечитайте вывод адверсариального разбора: для профиля GARAJ.KG система в целом не нужна, реально полезны только AgentShield (опционально) и идея детерминированного гейта качества через `hookify` (без ECC).
